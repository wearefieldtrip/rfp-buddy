eligibility, format and page limits, required attachments, and evaluation
criteria. Every requirement will cite its source (document and page or section).

`needs_review` until a person accepts, edits, or rejects it. A missing value is
shown as "Not found", never guessed. See `docs/ai-guardrails.md`.
