# Questions (deferred)

Not built yet. The **Question Library** sidebar link opens a placeholder.

**Planned:**

- A per-RFP _question log_: clarification questions for the issuer, with their
  status, submission deadline, and the issuer's answers.
- A cross-RFP _question library_: questions that come up often, with past answers.

AI may draft questions from gaps it finds in the RFP. A person approves each
question before it is sent, and the app never sends anything on its own.
